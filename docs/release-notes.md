Терминальный P2P-мессенджер на Go/libp2p: постоянные ключи Ed25519, подписанные сообщения, зашифрованный канал между собеседниками, WS/WSS, прямые TCP/QUIC-соединения, Circuit Relay и повторная доставка после недоступности узла.

Начиная с v0.2.1: общий `public-peers.txt`, обновление списка без новой сборки, выбор до трёх доступных соседей по RTT, общий сосед для публичных узлов, кэш на случай недоступности источника и динамические кандидаты AutoRelay. Добавить свой публичный узел можно через Pull Request; инструкции в `CONTRIBUTING.md`. Общий список пока пуст. Ручной `--bootstrap` сохраняет отдельную сеть; `--peer-list off` отключает загрузку списка.

Бинарники: Linux x86_64/arm64, macOS Intel/Apple Silicon, Windows x64. Go для запуска не требуется. Для первого подключения нужен адрес вашего публичного bootstrap-пира.

В релиз включены исходники, запускающие скрипты и `SHA256SUMS`. Инструкции: `docs/releases.md` в исходниках. Бинарники macOS не подписаны и не нотарифицированы.

Сообщения защищены при передаче, но IP и сетевые метаданные не скрываются. История и приватный ключ хранятся локально; история не зашифрована на диске. Подробности и ограничения: `PRIVACY.md`.
